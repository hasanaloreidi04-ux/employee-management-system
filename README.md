# Employee Management System

A professional full-stack employee management system built with Spring Boot, React, TypeScript, and PostgreSQL.

## Project Status

This project is currently under active development.

## Planned Tech Stack

### Backend

- Java 21
- Spring Boot
- Spring Security
- Spring Data JPA
- PostgreSQL
- Flyway
- Maven

### Frontend

- React
- TypeScript
- Vite
- Material UI

### Development Tools

- Git and GitHub
- Docker and Docker Compose
- Postman
- IntelliJ IDEA
- Visual Studio Code
